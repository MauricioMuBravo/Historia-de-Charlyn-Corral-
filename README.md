# Charlyn Corral · La historia de una campeona

Infografía interactiva en 3D sobre Charlyn Corral, delantera mexicana, pentacampeona de goleo en la Liga MX Femenil y ganadora del Trofeo Gerd Müller 2026 a la mejor delantera del mundo.

## Secciones
- **Portada**: balón 3D (Three.js) que sigue el cursor, con 176 goles orbitando.
- **Origen**: el Récord Guinness de 8,671 dominadas, en un cubo 3D.
- **Trayectoria**: carrusel 3D de Ecatepec a Pachuca y la Selección.
- **Goles 3D**: cancha con columnas de goles que se gira y se explora.
- **Récords** y **Palmarés**: tarjetas con inclinación 3D y trofeos que se voltean.
- **Autor**: créditos y redes.

## Tecnologías
HTML, CSS y JavaScript, con [Three.js r128](https://threejs.org/) cargado desde cdnjs. No requiere compilación.

## Estructura
```
index.html
css/styles.css
js/main.js
img/          fotografías
```

## Verlo en local
Abre `index.html` en el navegador, o sirve la carpeta:
```
python3 -m http.server 8000
```

## Publicar en GitHub Pages
1. Sube el contenido de esta carpeta a la raíz de un repositorio.
2. En **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`.
3. Tu sitio quedará en `https://<usuario>.github.io/<repositorio>/`.
